# P6: Full portfolio page structure in semantic HTML

This portfolio page introduces Satva Joshi and presents his education, project, hobbies, achievements, and contact information.

The page uses semantic HTML elements including `header`, `nav`, `main`, `section`, `article`, `address`, and `footer`. Navigation links jump to sections on the page. It has no CSS styling, as this exercise focuses on HTML structure.

Open `index.html` in a web browser to view the page.

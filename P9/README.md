# P9: Responsive navbar and card grid using Flexbox

This page has a sticky navigation bar and nine blue cards. Flexbox wraps the navigation links and cards when the screen becomes too narrow to fit them in one row.

The HTML is in `index.html`, and the Flexbox layout is in `style.css`. Each card keeps the positioned title overlay from P8.

Open `index.html` in a web browser and resize the window to see the layout wrap.
